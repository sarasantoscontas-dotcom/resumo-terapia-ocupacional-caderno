# Página comercial de Terapia Ocupacional

Versão aprovada pela proprietária em 22/10/2026. Abertura com caderno espiral vetorial, três apresentações independentes de 15 slides, matérias, resumos, referências, semestres, flashcards, funcionalidades e compra. Quantidades comerciais: mais de 2.600 resumos, 1.700 flashcards e 2.000 referências bibliográficas, conforme orientação da proprietária. Checkout e preço R$ 29,99 preservados.

`python content/build_refresh.py` gera a camada editorial `assets/study-refresh.js` a partir dos JSON desta pasta. O aplicativo e os conteúdos anteriores permanecem nos arquivos originais; a camada reorganiza a página após a montagem.

Validação: build estático, npm run check, npm run verify, integração DOM com navegação independente dos três slides, ordem das seções, quantidades e links de compra. Ilustração com texto vetorial para legibilidade.

Os conteúdos dos resumos foram elaborados com base em referenciais de TO, currículos oficiais da USP/UFSCar, AOTA, OMS, COFFITO e publicações institucionais. As apresentações de história usam o resumo fornecido pela proprietária. A organização em dez semestres é um percurso de estudo, não uma grade universal. A página comercial não altera o sistema de acesso nem cria os milhares de conteúdos anunciados.
