# Caderno do Acadêmico de Terapia Ocupacional

Versão independente baseada na estrutura, nos componentes e na identidade visual do site de Medicina. O repositório de Medicina foi consultado apenas para leitura; não foi modificado.

Oferta: R$ 29,99. Checkout exclusivo: https://pay.cakto.com.br/i2cyf2c . A configuração da página não altera o valor cadastrado na Cakto.

Conteúdos adaptados ao curso com base no catálogo existente de Terapia Ocupacional: ocupação, cotidiano, avaliação, análise de atividades, contextos, recursos, estágio, pesquisa e formação. Matriz e exemplos ilustrativos, sem registros reais de atendimentos e sem prescrição clínica. Referência complementar: AOTA, Domain and Process, OTPF-4 (https://www.aota.org/practice/domain-and-process).

Mantém os componentes do modelo: abertura, fichas, áreas, funcionalidades, planos, agenda completa, telas, pesquisa/TCC, flashcards, percurso acadêmico, públicos, benefícios, residência, FAQ, oferta e suporte. A grade foi adaptada aos oito semestres ilustrativos do catálogo de Terapia Ocupacional.

Sem instalação de dependências. `npm run check` verifica sintaxe. `npm run build` copia os arquivos para `dist/`. Vercel configurada para a pasta de saída. Fontes externas possuem alternativas CSS. Somente o checkout é redirecionamento comercial externo; as demais ligações são navegação interna.

Os arquivos de interface preservam o bundle React do modelo recebido; dados adicionais ficam em assets/expansion-content.json e as ampliações em assets/expansion.js. Os resumos e flashcards são conteúdo acadêmico para estudo; planos e telas exemplificam organização.
